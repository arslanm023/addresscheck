Upload today's order export files one by one. Every order's shipping address is checked, whatever its value — there is no £30 condition and no value priority anywhere. The billing address is ignored completely. Each shipping address must match exactly on all three parts — postcode, street, and town / county (state) — first against the free postcodes.io data, then against the Royal Mail preview: paste the address on Royal Mail, compare the preview result line by line, and only an exact match counts as verified. Any wrong or mismatched part flags the order — it is never passed as OK. There is no separate village / town breakdown and no guessed suggestion: the final suggested address is one simple line — exactly the accurate address the Royal Mail preview shows for that order (see the worked example in section 2). If the preview does not show an exact match for the exported address, the order is simply flagged “Manually verify this one”.

Each postcode is checked live via the free postcodes.io service: the postcode must exist, and the town and county (state) in the file must match the postcode's area — any mismatch is flagged, never passed. House number, street, town and county (state) rules are then applied to the shipping address of every order, whatever its value. The billing address is ignored — it is never checked or matched.

3Verify every order on the Royal Mail preview

Every order goes into the preview queue, worst first: HOLD, then FIX, then CONFIRM, then the rest — order value plays no part. Use Copy address for Royal Mail search on the order card, paste that one line into Royal Mail, and pick the accurate preview match — the postcode, street and town in the preview must match the shipping address exactly. Paste the preview address back into the order card and press Mark Royal Mail Verified: that pasted preview line becomes the order's final suggested address in the downloaded sheet. The checker re-checks the pasted address against the order's postcode, street and town — if nothing in the preview matches exactly, do not paste a near match: the order is flagged “Manually verify this one” instead.

How the preview queue works: the queue covers every order that is not yet verified — there is no £30 condition, no value priority, and no daily cap, because the check uses the Royal Mail preview: paste the address, read the address Royal Mail shows in the preview, and compare. Orders are ranked by severity only: P1 HOLD first, then P2 FIX, then P3 CONFIRM, then formatting-only and rule-passed orders; within the same severity, higher order value comes first as a tie-break only. An order leaves the queue only when its preview address is pasted in and marked verified — and the checker rejects a pasted address whose postcode, street or town does not match the order. An unverified order is never a final OK.

2 — Checked orders

Orders are shown in queue order: worst problems first (work from #1 down), then the orders that passed the rule checks and are waiting for their preview match. P1 HOLD means do not dispatch, P2 FIX means correct it first, P3 CONFIRM means a part of the shipping address does not match and must be resolved. P4 is formatting only. No order is OK until it is verified: an order counts as verified only when the Royal Mail preview address has been pasted in, marked verified, and its postcode, street and town all match the shipping address exactly — the checker rejects a pasted address that does not match. Orders that pass the automatic checks show PREVIEW CHECK until then.
How the final suggestion works — kept simple: copy the exported shipping address from the order card, paste it into Royal Mail search, and read the preview. The accurate preview match is the final suggestion — one simple address line, exactly as Royal Mail shows it, with nothing broken out into separate village or town columns. Worked example (fictitious, for training): the file shows “Rose Cottage, Northfield, ZZ9 9ZZ” and the Royal Mail preview shows “Rose Cottage, Chapel Lane, Little Millford, Northfield, ZZ9 9ZZ” — so that preview line, with the street (Chapel Lane) and village (Little Millford) that Royal Mail adds, is the final suggested address once it is pasted into the order card and marked verified. Those extra lines only ever come from the Royal Mail preview — the checker does not invent them, which is why an exported address like this one is missing them until the preview is pasted in. If the preview does not show an address that matches the exported address exactly, the order is flagged “Manually verify this one” and no guessed address is put forward as the suggestion. For HOLD orders the final suggestion stays empty until the exact Royal Mail address is pasted in and marked verified — the exported address is never copied into the final suggestion as if it were verified.

The team's daily routine

Royal Mail preview check — a couple of minutes per orderOn a queued order, use Copy address for Royal Mail search on the order card → open royalmail.com/find-a-postcode → paste the address and read the preview result → check the preview's postcode, street and town against the shipping address, part by part → paste the preview address into the order card here and press Mark Royal Mail Verified. That pasted preview address becomes the order's final suggested address in the downloaded sheet. If the preview shows no exact match, do not mark it verified — the order stays flagged “Manually verify this one”. Every order needs this, whatever its value.
HOLD ordersHOLD means the house number or postcode itself is missing or wrong — for example an order with only a street name and no number. Do not dispatch these. Get the house or business name and number from the customer first.
CONFIRM ordersCONFIRM means something in the shipping address needs a second look — for example the town does not match the postcode, or there is a house name but no number. Verify the shipping address on Royal Mail before dispatch. The billing address is ignored completely and is never checked.
End of dayDownload the Checked Sheet CSV and keep it — it records every order's status, issue, order value, queue position and verified address. Any order still in the preview queue at the end of the day is not verified — it carries over as the team's list for the next day, not as a checked order.

What this checker cannot do on its own: it cannot fetch the Royal Mail preview for you — the preview is read by the team on Royal Mail's own site. postcodes.io confirms that a postcode exists and which town and county it belongs to; it does not confirm the individual house, the street a named house sits on, or its village — those extra lines (Chapel Lane and Little Millford in the worked example above) only come from the Royal Mail preview. That is why the final suggested address in the downloaded sheet is the pasted preview address and nothing else: before the preview is pasted in and marked verified, there is no final suggestion — only the exported address, the checks on it, and, where the preview shows no exact match, a “manually verify this one” flag. Fine spelling differences (Alexandra vs Alexander, Yew Tree vs Yewtree, Upper Brow vs Upperbrow) also only show up on Royal Mail, which is why flagged orders must not skip the Royal Mail step, and why a HOLD order's final suggestion is never filled with a copy of the exported address.
